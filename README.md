# CRUD_DRF

A full-stack application utilizing Django REST Framework (DRF) as the backend to manage data and provide a RESTful API for a React Native frontend app.

## 🚀 Features

- **Django REST Framework**: Robust backend API development.
- **SQLite**: Lightweight database for development and testing.
- **React Native Frontend**: Seamless integration with mobile applications.
- **CRUD Operations**: Create, Read, Update, Delete functionalities for managing data.
